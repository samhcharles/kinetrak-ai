# Changelog

## [0.1.0] - 2026-05-20

### Added
- Initial release
- Real-time body pose, hand, and facial landmark tracking via MediaPipe Holistic
- Live camera overlay with vector skeleton rendering on canvas
- Three display modes: color video with overlay, black and white with overlay, tracking-only skeleton on black
- WebSocket output broadcasting live rig data for downstream consumers (game engines, motion capture pipelines)
- High-frequency telemetry HUD showing FPS and landmark data
- React 19 + TypeScript frontend powered by Vite
